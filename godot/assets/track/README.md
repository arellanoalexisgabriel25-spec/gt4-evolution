Asphalt textures are original procedural assets generated for GT4 Evolution using a fixed random seed; no third-party game imagery is used. The 1024×1024 maps are periodic and intended to repeat over the track. The normal map is visual only and does not change tire grip or collision.

Recreate with `python3 tools/generate_asphalt.py` (requires NumPy and Pillow for asset generation only).
